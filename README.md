# ComfyUI-PromptHistoryGallery

Пред-релизная версия, для сбора обратной связи./

Если у вас была база с прошлой версии ее лучше снести, обратную совместимость не реализовывал.
База находится тут \prompt_history_gallery\data\*.db *.db-wal *.db-shm


- Мультипромтинг не планируется.

- Сохранение стартового изображения для генерации i2i хотелось реализовать, но мусора становится слишком много, отказался от этой идеи, пока comfy ui не добавит функционал позволяющий это лучше реализовать чем, просто копировать каждый раз файл входного изображения, можно конечно один раз его скопировать на пачку, но логика приложения иная, у нас основа это промты а не виды настроек и переписывать логику нет желания. Это изначально приложение для того чтобы не потерять картинки с промтами и чтобы ими было удобно пользоваться.
  
- Импорт в базу оказался осуществимой задачей, но я все больше склоняюсь к тому, чтобы сделать стабильную версию и оставить ее в покое, пока она не сломается с очередным обновлением comfy ui.
